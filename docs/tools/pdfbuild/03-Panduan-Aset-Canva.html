Panduan Aset Canva — Petualangan Kuis

T1126-046 (REQ-9724)Panduan Aset Canva18 November 2026

Dokumen ini untuk desainer / klien yang menyiapkan gambar di Canva. Cukup ekspor file sesuai tabel, beri nama persis sama, dan kirimkan (atau taruh langsung di folder public/assets/canva/). Tidak perlu mengubah kode.

Semua slot bersifat opsional. Selama sebuah file belum ada, game tetap tampil rapi dengan gaya bawaan. Begitu file dimasukkan, tampilan otomatis berganti ke desain Canva.

2. Cara Ekspor dari Canva

  1. Buat desain dengan Custom size sesuai tabel (mis. 800 × 200 px).
  2. Klik Share → Download.
  3. Pilih PNG, centang Transparent background (perlu Canva Pro) untuk semua aset "PNG transparan".
  4. Untuk card-frame.png, atur Size × 2 agar tajam di layar retina.
  5. Untuk latar (bg-*.png) boleh pilih JPG kualitas ±80% agar file lebih kecil — tetapi ubah juga ekstensi di gameConfig.js (mis. bg-main.jpg).
  6. Ganti nama file sesuai tabel (huruf kecil semua, pakai tanda hubung).

3. Batas Ukuran File (agar game cepat dimuat)

Jenis aset Target maksimal
Latar belakang ≤ 400 KB
Frame / tombol ≤ 150 KB
Maskot / badge ≤ 120 KB
Ilustrasi soal ≤ 250 KB

Bila terlalu besar, kompres dengan tinypng.com sebelum dikirim.
