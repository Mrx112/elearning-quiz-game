# Folder Aset Canva

Taruh file hasil ekspor Canva di sini dengan **nama persis** seperti di bawah,
lalu refresh browser. Jika file belum ada, game otomatis memakai tampilan bawaan.

| Folder         | File                                   | Ukuran ekspor   | Format            |
|----------------|----------------------------------------|-----------------|-------------------|
| `backgrounds/` | `bg-main.png`                          | 1920 × 1080 px  | PNG / JPG         |
| `backgrounds/` | `bg-mobile.png` (opsional)             | 1080 × 1920 px  | PNG / JPG         |
| `ui/`          | `logo.png`                             | 1200 × 400 px   | PNG transparan    |
| `ui/`          | `card-frame.png`                       | 1600 × 900 px   | PNG transparan    |
| `ui/`          | `btn-option-1.png` … `btn-option-4.png`| 800 × 200 px    | PNG transparan    |
| `ui/`          | `btn-primary.png`                      | 600 × 160 px    | PNG transparan    |
| `characters/`  | `mascot-idle/happy/sad.png`            | 512 × 512 px    | PNG transparan    |
| `badges/`      | `badge-gold/silver/bronze.png`         | 512 × 512 px    | PNG transparan    |
| `badges/`      | `star-on.png`, `star-off.png`          | 256 × 256 px    | PNG transparan    |
| `questions/`   | `q1.png` … `q5.png`                    | 1200 × 675 px   | PNG / JPG         |

Panduan lengkap: `docs/PANDUAN-ASET-CANVA.md`
